No internet

Clean offline state: green cloud outline with a single diagonal line, “No internet” below it.

What changed
  • The raw network exception is no longer shown — any fetch-level failure (offline, DNS, dropped connection) renders the friendly state instead.
  • Cloud icon is drawn as an outline in the app’s brand green (#1f4d3f) with one diagonal line crossing it.
  • “No internet” sits directly below the icon, with the existing Try again action under it.
  • Applied to Discover, My Partners and Requests tabs — previously the last two showed a blank sheet when offline.
  • Ships in both the Android/iOS app and the web app, keeping the two in sync.
