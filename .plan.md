## Phase 1 (NOW): Standalone demo HTML for the client

**Create `android-bugfix-demo.html`** at project root — one self-contained file (inline CSS/JS, Google Fonts with system fallbacks), in the style of the existing `deletion-dialog-options.html`.

Contents:

1. **Android device frame** (per client request: latest Android look)
   - 412×915 dp screen (Pixel 9-class), auto-scaled to fit the browser window
   - Centered punch-hole front camera in the status bar
   - Latest Android status bar: clock **left**, wifi / signal / battery **right** (Material You style)
   - Bottom gesture-navigation pill; thin dark bezel

2. **Bug 1 — Tile Game fullscreen** (Before/After segmented toggle)
   - Playable Memory Match replica (Restart pill, Fraunces title, ✕, ⏱/🎯 stats, 4-col green tile grid) that opens fullscreen inside the frame
   - **Before**: content starts at y=0 → Restart overlaps the clock, ✕ overlaps wifi/battery (exactly the client screenshot)
   - **After**: `padding-top = status-bar (28px) + 12px` → header clears the status bar; bottom padded above gesture pill

3. **Bug 2 — Back navigation** (Before/After toggle + visible history-stack strip)
   - Mini app: Home ⇄ Partners tab, push Flashcards detail, sub-view inside it
   - Top bar shows burger on root tabs, back on pushed screens
   - **Before**: every back press (top-bar arrow **and** an "Android back" chip simulating hardware back) jumps straight to Home (`firstRoute` behavior)
   - **After**: back returns to the actual previous screen/sub-view; hardware chip walks the stack correctly

4. **Bug 3 — Back-animation white line** (Before/After toggle, replay button)
   - Two app pages replaying the real Android 13+ back transition (incoming slides −10%→0, outgoing fades ~83 ms + slides +10%, 450 ms, fast-out-slow-in)
   - **Before**: white underlayer shows as a shrinking column on the right edge during the animation
   - **After**: same animation but the underlayer is painted paper (`#f1f4f0` light / `#14110c` dark) → line invisible

5. MedConnect design language throughout: forest `#1f4d3f`, paper `#f1f4f0`, gold/rust accents, Inter + Fraunces, short "Before (bug)" / "After (fix)" captions.

**Verify**: open the file in a browser, exercise every toggle/replay at phone scale, check layout at small window sizes.
